Make a sanitized HAR copy

Build a reduced HAR by keeping only known timing and request-metadata fields. All header, cookie, query and form values are replaced; body text, page titles, server IPs, comments and vendor metadata are removed. This also removes credentials inside headers that were not recognized by name.

Choose a HAR to make a separate sanitized copy.
